# Evaluation and Evidence 可视化

本页对应 2026-11-03 新增的真实证据仪表板。它读取实际 scene-0980、stage3/5/6 和 M3 交付，不使用此前 synthetic demo 的虚构复访数据。

## 运行

```bash
python3 scripts/build_evidence_demo.py --out outputs/evidence-demo-new
```

用浏览器打开输出目录的 `index.html`。HTML 自包含，无需安装前端依赖或联网加载地图。构建代码需要 Python 3.10+ 标准库和仓库已有资料；构建后使用页面不需要 Python。

## 页面

- 场景证据：真实地图、41 帧时间线、有序观测标线、占用物体轮廓、自车与标注车辆。选择候选可跳转到该候选窗口；本帧无观测会明确显示，不被解释为恢复。
- 评估结果：从 126 条已交付的受控窗口记录重新计算三种方法、六个分组的指标，核对全部 18 行交付评估表。F1 与判定覆盖率、全部正例检出率同时展示；低覆盖组没有判定时条件 F1 为未知。真实场景缺少独立标签，P/R/F1 保持不可计算。
- 证据链：7 个 M3 复核对象，以及精确帧窗口、地图身份、局部诊断和未决原因。点击复核项返回地图，展开侧栏可追到源文件。

“自动演示”依次查看 LD004、多帧观测、LD003、道路占用、评估表和证据链。导出按钮根据当前页面导出所选证据、所选评估分组或复核清单。

灰色关联线要求：该候选—行为片段已判为 associated；当前帧确有该车辆、占用轮廓与距离记录；距离不超过 3 米。线条终点投影到实际占用轮廓边界，不根据整段最小距离在每一帧固定显示。关联表示时空邻近，不表示因果。

## 评价的分母

- 已判定样本 F1：2TP / (2TP + FP + FN)，未决样本不混入这张二分类表。
- 判定覆盖率：(TP + FP + TN + FN) / 全部试验窗口。
- 全部正例检出率：TP / 全部有注入变化的窗口，包括未决正例。
- 已判定负例误报率：FP / (FP + TN)。分母为 0 时保持未知。

质量门控方法在全部组上为：TP=24、FP=0、TN=9、FN=3，证据不足 42、需要复核 48。因此条件 F1 为 94.1%，判定覆盖率为 28.6%，全部正例检出率为 22.2%。不能只拿 94.1% 当作整个真实项目的准确率。

受控样本来自同一场景的三个基准窗口，彼此并非独立真实场景。“未变化”标签仅表示没有注入偏移，并非独立确认道路未变。匹配关系沿用原有结果，不评价扰动后的重新匹配性能。

## 实现与验证

- `map_update/evaluation.py`：分组指标重算、拒判处理、交付表比对、真实场景与受控数据隔离。
- `map_update/evidence_dashboard.html`：无第三方依赖的前端，SVG 地图、逐帧播放、候选联动、指标图表与 JSON 导出。
- `scripts/build_evidence_demo.py`：加载原始数据、重新执行 M3 连接检查并构建页面。
- `tests/test_evaluation.py`：新增 7 项测试，保护分母、未知值、重复样本、真实/受控数据分离和评估表可复现性。
- `scripts/check_evidence_demo.py`：24 项浏览器检查，涵盖实际记录、精确帧关联、图层开关、证据导出、分组切换、自动演示和移动端布局；可生成实际浏览器状态串联的 MP4/GIF。

```bash
python3 -m unittest discover -s tests -v
# 浏览器检查另外需要 Playwright、Chromium；录制需要 ffmpeg。
python3 scripts/check_evidence_demo.py outputs/evidence-demo-new --record
```
