# 三维地图展示（2026-11-09）

当前地图增加 Three.js 三维视图，默认从选中事件附近的街道尺度进入。地图处理结果沿用已冻结的实质结构判断；本次只更新展示，不重新训练或修改分类结果。

## 操作

- 默认进入 **3D 立体**；拖动旋转、右键拖动平移、滚轮或右下角按钮缩放。
- 手机单指旋转，双指缩放和平移。
- **倾斜视角／垂直俯视／重置视角**控制相机；**完整地图／定位选中**调整观察范围。
- 继续用中间分割线比较原图与更新后：最右全原图，最左全更新后。两边共用同一相机、视口和坐标变换。
- 点击黄色状态或红色结构变化查看对应记录。原图一侧不会选到仅存在于更新后侧的事件。
- **2D 平面**保留原显示，也可在网址使用 `?view=2d`。中英文切换保留视图选择；浏览器不支持三维时自动回到二维。

## 显示与数据边界

底图位置、车道边界、横道及事件轮廓来自已有 XY 几何。道路平面经过透视渲染；标线和路面之间的微小显示高度仅防止遮挡，不表示真实海拔。黄色状态轮廓的 1 m 立体高度为示意，未读取真实建筑高度或重建城市地形；界面明确注明。未在片段末帧观测到的状态保留空心轮廓，不解释为已解除。

黄色仍代表状态事件；红色仍代表已采用的实质结构变化。nuScenes 的 23 个状态和 6 个本次不改图的结构候选保持；Argoverse 默认展示 93 项参考地图副本变化，完整 98 项审计仍保留。参考回放与独立模型输出继续分开。

相机将城市坐标减去局部原点后映射为 `(x - origin_x, display_height, -(y - origin_y))`，保持 XY 位置。修改前后分别用裁剪区域渲染，共享投影矩阵，拖动分割线不拉伸任何一侧。

## 实现与复现

- `map_update/pipeline_map_3d.js`：场景、道路与事件网格、共享相机、裁剪、拾取及手势。
- `map_update/pipeline_studio.js/html/css`：三维／二维切换、控制条、来源详情与回退。
- `map_update/vendor/`：固定版本 Three.js 0.180.0、MIT 许可证及完整性记录；网页无需访问外部 CDN。
- `scripts/check_pipeline_3d.py`：真实 Chromium WebGL 渲染与交互检查。

```bash
python scripts/build_pipeline_studio.py --result outputs/pipeline-v6/material-structure-20261109/result.json --out outputs/pipeline-v7/three-dimensional-20261109
python -m unittest tests.test_pipeline_presentation_identity -v
python scripts/check_pipeline_3d.py outputs/pipeline-v7/three-dimensional-20261109
python scripts/check_pipeline_studio.py outputs/pipeline-v7/three-dimensional-20261109
python scripts/check_composite_map.py outputs/pipeline-v7/three-dimensional-20261109
```

输出目录应使用新目录。旧二维回归脚本明确请求 `view=2d`；三维脚本检查实际 WebGL 像素、原始坐标、相同相机、左右裁剪、点击、缩放、手机手势、二维回退以及原始结果不被修改。

最终验证：14 项展示身份测试、44 项三维浏览器检查、174 项二维回归检查通过；冻结结果、地图及状态导出逐字节保持不变。浏览器检查使用 Playwright、Chromium 与 Pillow。详见 `three_dimensional_release_validation_20261109.json`。
