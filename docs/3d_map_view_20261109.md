# 三维地图展示（2026-11-09）

当前地图使用 Three.js 三维视图，并按原始标注显示路障和锥桶造型，默认从选中事件附近的街道尺度进入。地图处理结果沿用已冻结的实质结构判断；本次只更新展示，不重新训练或修改分类结果。

## 操作

- 默认进入 **3D 立体**；拖动旋转、右键拖动平移、滚轮或右下角按钮缩放。
- 手机单指旋转，双指缩放和平移。
- **看路障／看锥桶**直接定位真实来源事件；**物体造型**可切换立体造型与原始占地轮廓。
- **倾斜视角／垂直俯视／重置视角**控制相机；**完整地图／定位选中**调整观察范围。
- 继续用中间分割线比较原图与更新后：最右全原图，最左全更新后。两边共用同一相机、视口和坐标变换。
- 点击黄色状态或红色结构变化查看对应记录。原图一侧不会选到仅存在于更新后侧的事件。
- **2D 平面**保留原显示，也可在网址使用 `?view=2d`。中英文切换保留视图选择；浏览器不支持三维时自动回到二维。

## 显示与数据边界

底图位置、车道边界、横道及事件轮廓来自已有 XY 几何。道路平面经过透视渲染；标线和路面之间的微小显示高度仅防止遮挡，不表示真实海拔。当前 23 个状态事件的最后保存观测匹配到 49 个不同实例：35 个路障、11 个锥桶和 3 个杂物。路障使用有宽底和斜面的通用模型，锥桶使用底座、锥形桶身与反光带。全部 49 个对象都有原始长、宽、高和朝向；立体模型按这些尺寸放在展示地面上，来源全局 Z 不当作路面海拔。3 个杂物缺少具体外形信息，保留占地轮廓。外观颜色、材质和反光带是类别示意，不是图像恢复出的真实表面。未在片段末帧观测到的状态保留半透明造型与空心标记，不解释为已解除。

物体来源为 `processed/objects.csv` 和 `processed/frames.csv`。展示适配器按状态记录保留的 frame/instance 身份、sample token、时间戳、类别和轮廓顺序逐项核对；从同一帧的源尺寸和朝向重建矩形，只允许 1e-7 m 的浮点误差。事件的首帧几何不替代最后观测几何，重复帧不复制成新物体；无法严格匹配的对象退回原始轮廓，不按距离猜身份。当前匹配失败为 0。各事件可能来自不同最后观测时刻，不能当作同一时刻完整场景。

这是已有标注驱动的展示，不是重新运行传感器目标识别或三维网格重建。独立导出 `nuscenes_state_object_presentation.json`，包含每个实例的来源 ID、姿态、尺寸和 SHA256。输入预测和状态图层保持不变。

黄色仍代表状态事件；红色仍代表已采用的实质结构变化。nuScenes 的 23 个状态和 6 个本次不改图的结构候选保持；Argoverse 默认展示 93 项参考地图副本变化，完整 98 项审计仍保留。参考回放与独立模型输出继续分开。

相机将城市坐标减去局部原点后映射为 `(x - origin_x, display_height, -(y - origin_y))`，保持 XY 位置。修改前后分别用裁剪区域渲染，共享投影矩阵，拖动分割线不拉伸任何一侧。

## 实现与复现

- `map_update/state_object_presentation.py`：按保留观测的确切身份生成展示描述，不影响预测。
- `map_update/pipeline_map_3d.js`：场景、道路与事件网格、共享相机、裁剪、拾取及手势。
- `map_update/pipeline_studio.js/html/css`：三维／二维切换、控制条、来源详情与回退。
- `map_update/vendor/`：固定版本 Three.js 0.180.0、MIT 许可证及完整性记录；网页无需访问外部 CDN。
- `scripts/check_pipeline_3d.py`：真实 Chromium WebGL 渲染与交互检查。

```bash
python scripts/build_pipeline_studio.py --result outputs/pipeline-v6/material-structure-20261109/result.json --out outputs/pipeline-v8/semantic-objects-20261109
python -m unittest tests.test_state_object_presentation tests.test_pipeline_presentation_identity -v
python scripts/check_pipeline_3d.py outputs/pipeline-v8/semantic-objects-20261109
python scripts/check_pipeline_studio.py outputs/pipeline-v8/semantic-objects-20261109

```

输出目录应使用新目录。旧二维回归脚本明确请求 `view=2d`；三维脚本检查实际 WebGL 像素、原始坐标、相同相机、左右裁剪、点击、缩放、手机手势、二维回退以及原始结果不被修改。

25 项来源／展示单元测试、62 项三维浏览器检查及 174 项二维检查全部通过；原结果与导出逐字节保持。此次验证覆盖来源精确匹配、真实源尺寸与朝向、类别造型、未知类别回退、状态生命周期、造型开关和原有二维／三维交互。最终检查记录见 `semantic_object_release_validation_20261109.json`。浏览器检查使用 Playwright、Chromium 与 Pillow。
