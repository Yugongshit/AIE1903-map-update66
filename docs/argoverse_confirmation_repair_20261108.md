# Argoverse：确认、识别与地图写入分开处理

本次修复“数据已经标注变化，但网页仍全部显示未确认”的问题。用户指定的颜色保留：状态事件为黄色，正向结构变化为红色，未确认候选为绿色。红色的来源现在明确区分为**交付真值**或**算法检出**；写入状态单独显示。

## 原因与修改

1. 旧几何检测遇到 prior `NONE` 就一票否决。这批真值里，34 条发生几何变化的车道边界参考记录恰好全部为 `NONE`。现在对所有可匹配边界运行相同的局部几何检验；没有油漆不再使几何检验自动失败。
2. `NONE` 不再统一被解释为“新增油漆”。几何、标线存在性、标线属性、车道用途和拓扑是不同问题。当前感知曲线可支持几何差异预测，但不能凭曲线推断颜色、虚实线、车道用途或连通关系。
3. 新 `model_change_decision` 根据观测计算 `detected`、`no_geometric_discrepancy` 或 `insufficient_evidence`，不再把确认结果固定为 false。其明确范围是**局部几何对应**，并不是整条地图要素的修改许可。
4. 网页算法视图的红色读取模型判定，不再读取“允许写入/已写入”。对齐、完整修改几何等缺项只影响相应写入条件，不再把已检出的局部差异改称不存在。
5. 增加独立的“已确认数据变化（真值回放）”视图。M8 已提供的完整对象修改在隔离地图副本上实际执行，并保存修改前后状态、版本和回退结果；这不计作模型识别成功。

## 使用的方法

保留固定地图位置的多帧比较：合并共享物理边界，检查曲线质量、参考匹配方向和歧义，在同一锚点计算有符号偏移，将相邻观测聚合到 0.5 秒块，再使用中位数、MAD 和同方向支持比例判断局部几何差异。

本次没有调整原数值条件：至少 3 个时间块、跨度至少 1 秒、偏移超过 0.5 米、MAD 不超过 0.35 米、同方向支持至少 70%。修复的是错误的语义否决和结果处理方式，不是为了通过某个真值案例而调整阈值。方法是可解释的工程基线，没有训练或宣称校准过的概率。现有单开发场景不足以证明一个学习模型优于该基线。

几何一致仅表示局部曲线关系一致，**不能据此认定标线属性或道路用途都未改变**。未匹配新增对象、横道、属性和拓扑变化尚无完整感知检测分支；网页真值回放能够呈现这些已知变化，但不会伪称算法已独立检出。

## 本次完整运行结果

Argoverse 的 76 个观测窗口中，14 个检出局部结构差异、40 个观测支持不足、22 个局部几何一致。数据集名称和变化标签没有进入预测。

评价范围改为所有先验物理边界，包括无标线边界：343 个物理边界中，3 个共享引用的真值相互冲突，单列为不可评；其余 340 个中有 31 个几何变化正例。

| 同一评价范围 | 旧 NONE 否决条件 | 修复后 |
| --- | ---: | ---: |
| 命中已变化边界身份 | 0 | 9 |
| 在未变化边界上报出差异 | 1 | 5 |
| 漏检已变化边界 | 31 | 22 |
| 边界身份检出精确率 | 0% | 64.3% |
| 边界身份检出召回率 | 0% | 29.0% |

旧条件对照使用同一批冻结观测及同一数值策略，仅恢复原 `NONE/UNKNOWN` 否决，评价分母完全相同。这不是两个独立测试集的成绩。

**9 个边界身份命中不等于 9 份正确修改几何。** 另在相同锚点对照当前真值，14 个检出中只有 3 个的偏移误差在 0.5 米以内：`ls-168085027/right`、`ls-168054317/right`、`ls-168085012/right`。其余检出仍存在对应或投影误差。因此当前不把模型的局部曲线自动覆盖整条道路，模型自动底图补丁仍为 0。这是明确的精度限制，不再藏在“全部未验证”里。

这些指标来自同一个 `constructed_train` 开发场景；分母包含未观测区域，不是可见区域准确率，也不是独立测试准确率。98 个变化对象覆盖多种变化类型，与 31 个可评几何边界正例是不同单位。

## 已确认数据的地图更新回放

M8 有 98 个已确认变化对象：89 个车道对象和 9 个横道对象。执行 **27 次新增、71 次替换**，更新副本得到 240 个车道、33 个横道；全对象状态与交付当前地图相符。修改包含几何、标线属性、用途和连接字段，回退恢复原地图全部对象、顺序和元数据。原始地图文件没有被覆盖。

网站默认在 Argoverse 展示该回放，98 个变化对象为红色，并清楚标注“数据真值”。切换到算法视图后，显示 14 个红色局部检出、40 个绿色证据不足候选、22 个灰色几何一致记录。原图/更新后图仍共用坐标：分割线最右为原图，最左为更新后图。

## 输出与复现

最终运行目录：`outputs/pipeline-v4/confirmation-final-20261108/`。

- `argoverse_predictions.json`：不含真值回放的冻结模型预测。
- `prediction_freeze.json`：读取 M8 前保存的预测文件哈希。
- `result.json`：模型结果、事后评价和带明确来源的真值回放。
- `argoverse_reference_updated_map.json`：已执行 98 个真值补丁的地图副本。
- `argoverse_reference_rollback_map.json`：回退后的原图内容。
- `argoverse_reference_patch_log.json`：每次修改的前后状态和操作。
- `argoverse_reference_changes.geojson`：98 个已确认变化对象的可视化图层。

```bash
python scripts/run_change_pipeline.py --out outputs/pipeline-v4/new-confirmation-run
python scripts/build_pipeline_studio.py \
  --result outputs/pipeline-v4/new-confirmation-run/result.json \
  --out outputs/pipeline-v4/new-confirmation-site
python -m unittest discover -s tests -v
python scripts/check_pipeline_studio.py outputs/pipeline-v4/new-confirmation-site
python scripts/check_composite_map.py outputs/pipeline-v4/new-confirmation-site
```

输出目录须不存在。预测先保存并冻结，再读取 M8；真值回放完成后再次校验冻结哈希。源数据与模型输入不改写。nuScenes 的 23 个状态事件及两个数据集的状态层导出与修复前逐字节一致。
