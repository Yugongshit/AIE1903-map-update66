# 后续目标：场景生成器统一生成交通

用户已明确：当前交通区域、交通模式、跟车模型、驾驶风格、车辆数量、速度差异与事件控件是开发和实验入口，不是最终产品终点。最终应由场景生成器联合生成这些因素，可以单一，也可以混合；保留人工配置、接管及投放事件的可能性。本轮只调整设计，不实现全量自动生成或虚构训练成果。

## 目标入口

- **拟真交通**：在可用真实数据支持下校准流量、速度、头距、驾驶风格和事件分布，尽可能模仿现实。没有足够数据时明确说明未校准，不能仅因“随机”就标为逼真。
- **多样化测试**：系统覆盖稀疏/拥挤、单一/混合行为与少见事件。可有意识增加危险事件，但其概率属于压力测试配置，不冒充现实事故频率。
- **人工配置与干预**：允许固定部分条件，其余仍自动生成；后续选车驾驶、局部投放事件。人的未来动作不属于生成器已知答案。

当前界面暂时保留原控件以便验证；以上入口尚未实现。

## 技术结构

1. 读取真实地图的车道图、交叉口、可达性、有效出生/回收区域和已有占用，形成约束。不能为了生成交通虚构道路或真实建筑。
2. 从场景条件联合采样区域、路线/起终点、流量、参与者类型、行为模型和风格。禁止把所有控件独立均匀随机后拼起来：密度需符合道路容量，速度需匹配曲率与通行条件，行人应有可用过街路径，行为参数应匹配相应模型。
3. 每个场景可指定统一风格，也可为不同参与者生成混合风格。行为模型选择也受约束；旧制动基线用于科研对照，不应为了“多样”在拟真模式中与较可信模型无条件等概率混用。
4. 事件生成器按场景类型采样触发条件、位置与持续时间。临时占道、失能车辆、长期施工需要不同时间分布；在确认安全出生后执行实体变化，不在车辆身上生成障碍，不瞬移参与者。
5. 物理执行器只执行当前动作与当前事件；观测层从当前物理世界产生观测；地图更新只读观测。生成器计划、种子、未触发事件和未来玩家动作都不进入 Planning 接口。

基础生成方法先是地图约束下的随机程序与校准行为模型；有足够独立场景后再训练流量/行为联合模型或 IDM 残差模型。使用既有模型必须有基线和消融，不能把随机数生成器称为已训练 AI。

## 随机性与复现

统一场景种子下，为道路/出生、驾驶风格、行人、事件触发、清障等建立独立随机流。同种子、同配置与同执行环境应可复现；修改清障分布不应改变初始车辆位置。换种子生成新的实验，而“重置同一场景”应复现同一次抽样，不在每个物理步重新抽签决定是否清障。

后续保存完整实验清单：生成器版本、地图版本、原始约束、采样后的配置、随机种子、外部控制与已发生的人工操作。清单供复现和事后评价，不交给被测 Planning 获取未来答案。当前已落地的独立随机流包括驾驶风格、施工点数量、施工点位置与各处施工清障；完整实验清单仍待实现。

清障当前默认三角分布范围 45–120 仿真秒，峰值 70 秒，偏向较短的临时占道；它是演示先验，不是实际施工时间统计。范围可调到 5–3600 秒，并明确仿真时钟和采样规则。将来若压缩真实分钟/小时级事件，需要公开时间缩放规则；不能悄悄声称几十秒代表真实大型施工。

## 推进次序与评价

阶段二已加入参与者与事件基线：源横道行人过街、失能/真实碰撞停驶状态、三条源道路路线、保守路口冲突处理、安全出生与后续施工。车辆保持循环、行人往返，未实现城市边界流入/流出。下一步可把这些能力交给统一生成器有约束地组合与校准。人工操作入口后置。阶段三加入遮挡/噪声与覆盖可信度；阶段四连接同学自己的 Planning；阶段五评估地图更新的下游价值。

生成效果分别看真实性和覆盖多样性。用真实独立场景检验速度、加速度、头距、流量等分布，用多种子测量死锁、碰撞、越界、安全干预率与长时持续运行；不要用“事件更多”替代真实程度。地图效果实验必须固定同一套物理初态、生成规则和随机种子，只改变 Planning 收到的地图，不能同时随机更换交通环境或控制器。

多点施工与阶段二持续混合交通已作为生成器能力基线；运行中新增施工要求离开全部受控车的当前观测范围并通过占用检查，不能无条件保证发生频率。这仍是地图约束的随机程序，不是已训练模型。
