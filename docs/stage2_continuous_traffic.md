# 阶段二：可持续混合交通基线

阶段二提供一个可运行、可复现的交通世界：多条源道路路线、背景跟车与路口让行、行人过街、车辆临时失能及实际碰撞后的停驶、持续发生并清除的施工占道。它是低速仿真基线，不是已训练的拟真城市生成模型，也不是同学的 Planning 算法。

## 打开与查看

```bash
cd ~/Desktop/AIE1903-map-update66
git pull --ff-only origin main
conda activate aie1903-sim
python scripts/run_simulation_platform.py --port 8093
```

浏览器打开 `http://localhost:8093`，强制刷新。选择 nuScenes scene-0980，右侧“交通实验”默认 **阶段二持续交通 · 多路线**、**混合事件 · 行人 / 失能 / 持续施工**。建议保留默认 8 车、混合驾驶风格、快慢 ±30%、开场 2–3 处施工、45–120 仿真秒清障。

点击“启动或恢复场景”，然后“开始服务器”。已有房间需要房主先关闭，才会应用新配置；“退出观看”不关闭世界。仿真时钟可以超过原始记录的 20 秒，暂停期间事件时钟也暂停。

- “全图”查看多路线交通；观察车辆查看该车的局部地图与 Planning 输入。
- “查看下一位行人”定位有紫色标签的仿真行人；“查看当前失能车”切换到事件车辆。
- 施工点用橙色及独立编号显示，“查看下一处路障”轮流定位。R 编号表示运行中新增的施工点。
- 面板统计过街次数、失能发生/恢复次数、后续施工次数、安全条件不足的延后次数和路口通行次数。这些是观众统计，不属于 Planning 观测。
- 原“单闭环交通 · 对照”仍可选择。也能单独选择行人、车辆失能、开场施工、定时停车或无预设事件。

## 交通如何持续运行

从原地图显式的 `exit_lanes` 连接提取闭环，过滤中心线不简单、与源物体太近等候选，选择三条相连的源道路路线，长度约 395、606、653 米；共享路段不应重复算成新增道路里程。每辆车有独立的安全出生位置和沿自身路线的往返任务目标，完成后继续沿道路循环，不瞬移、不倒放。当前不是任意城市起终点，也没有自由变道或随意铺设连接道路。

出生车身之间额外保留间距，并避开路口冲突区。最多 12 辆；无法满足安全出生条件时拒绝创建并要求降低数量。没有用删除、搬动车辆或重置位置解决拥堵。长期循环复用这批车辆，不声称已实现城市边界的车辆流入/流出模型。

横向仍用纯追踪，纵向可用 IDM 与当前邻车状态，加上现有物理近场制动。期望速度限定在 0.5–3 m/s；混合风格参数尚未拟合真实驾驶数据。

## 路口规则

从所选源车道图中的分流/合流提取四处冲突区，采用保守的无信号路口预约规则：按到达次序让各方向队首车辆依次通过，跟车不能抢到前车之前的预约。当前实体尚占据冲突区时不放行新的方向；未进入且长期被挡的预约可以撤销重排。外部控制车只作为物理占用被检查，协调器不给 ego 下发规划动作。

这是仿真背景交通规则，不是 nuScenes 的真实信号灯相位，也不是完整道路交通法规实现。没有真实灯态时不会虚构红绿灯。后续拟真交通校准、信号控制、变道和更多道路类型属于增强工作。

## 行人与物理近似

仅选择与运行路线相交的原地图 `CROSSWALK` 多边形，沿其长轴建立往返过街路径，不生成虚构的人行道。检查初始实体占用与过街路径间距；可用横道不足时显示实际人数和容量受限，而不是把人塞进车身。默认最多 3 人，可配置 1–4 人。

行人使用 0.6 × 0.6 × 1.7 米的 MetaDrive/Bullet 刚体，速度在 0.8–1.4 m/s 中按种子抽取。等待后检查当前实体及当前速度外推的安全间隙，再过街；到另一端等待后返回。位置由物理步推进，运行中不改位置来“跳过去”。速度伺服和站立约束是近似，不模拟步态、生物力学或伤害。过街安全检查不能被描述为能保证任意外部驾驶动作下不碰撞。

行人进入本车当前 50 米范围才进入局部观测；不会因为行人静止就把横道写成永久封路。

## 失能与事故响应

启用车辆事件后，初次临时失能在 20–40 仿真秒内抽样；恢复后间隔 25–55 秒再尝试下一次。只选择内置 AI 正在控制、且不在路口/横道附近的车辆。通过真实制动降速，停下后进入失能状态，12–25 秒的抽象修复窗口结束后恢复控制。不会修改车辆位置，也不在运行中凭空放置撞毁车辆。

实际物理碰撞会触发另一条状态路径：碰撞记录 → 制动/停驶 → 25–45 秒抽象修复 → 交还原控制模式。该状态也约束外部控制车的执行动作，表示抽象执行器失能，不替外部算法规划路线。正常混合场景不故意用内置 AI 撞车；碰撞专项由测试客户端施加动作产生真实接触，验证停驶及恢复。随机故障不能冒充真实车祸。

不模拟车身形变、墙体破坏、乘员伤害或拖车。地图更新只将持续静止的车辆识别为足迹占用，不直接读取“事故”或“失能”的生成器标签来判断封路。

## 后续施工事件

开场施工仍按数量区间、位置和各处时长独立抽样。混合模式还会在运行中尝试新增施工点：首次间隔 45–70 秒，成功后间隔 30–60 秒；当前在场数不超过配置上限。每处持续时间仍在配置的清障区间中独立抽取。

新增位置必须在所有受控车辆当前 55 米外、远离当前实体、路口和行人路径，且沿已有源道路安全候选选择。任何条件不足就延后 5 秒重试。不能为了保证“每分钟一定出事”而重叠出生或在玩家眼前突然冒出来。观众视角仍能看到新增，这是全局诊断视角；Planning 只能获得本车的当前范围观测。

新增与清除仍为离散事件，不模拟施工队铺设或搬运过程。默认分布是演示/压力测试先验，不是真实事故率或施工频率。观众详细施工历史最多保留 64 个已清除事件，累计计数独立保留。

## 地图和 Planning 的边界

链路保持为：物理世界变化 → 当前局部观测 → 足迹占用证据 → 版本化状态层 → 外部 Planning 接口。当前理想观测没有遮挡或噪声；事故原因、行人未来目标、事件期限和随机种子不进入 `/perception` 或 `/planning-input`。

切换“接收观测产生的状态更新 / 固定底图”不会改变当前物理世界。临时占用不等于永久道路改写，结构写入仍为 0。真正的地图对照效果、轨迹预测及同学规划器的动态重规划，要等实际接入后评价；此处没有实现同学的整个规划算法。

同版本、同配置、同种子、同外部动作序列及执行环境下复现。外部动作改变后，安全出生检查与真实碰撞也可能改变，不能仅凭相同种子就声称物理轨迹必然相同。阶段五需要固定或重放同一物理世界/外生事件条件，并记录完整实验清单。

## 接口与验证

`traffic` 新增字段：

| 字段 | API 默认值 | 作用 |
| --- | --- | --- |
| `route_mode` | `single` | `single` 单闭环；`network` 多源道路路线 |
| `pedestrians` | `false` | 启用源横道行人 |
| `pedestrian_count` | `3` | 请求人数上限，整数 1–4 |
| `incidents` | `false` | 临时失能与物理碰撞停驶/恢复 |
| `recurring_construction` | `false` | 运行中安全条件满足时生成新施工 |

网页默认启用阶段二混合模式；API 保留旧默认值以便对照。观众 `/state` 返回 `population`、`junction_control` 和各类当前 `synthetic_events`。这些字段不属于局部观测合同。多路线通过源车道引用传输，避免重复几何超过工作进程消息限制。

```bash
python -m unittest discover -s tests -v
python scripts/validate_stage2_traffic.py --out outputs/stage2-check --seconds 600
python scripts/validate_stage2_traffic.py --out outputs/stage2-density --seconds 600 --seed 7 --cars 12
python scripts/validate_construction.py --out outputs/stage2-collision --collision-probe --incident-response
python scripts/check_stage2_traffic.py --url http://127.0.0.1:8093 --out outputs/stage2-browser-check
```

验收检查：三条源路线的车辆持续前进、路口能让行并通行、行人完成多次真实物理过街、临时失能能恢复、新施工满足观测范围外出生条件、观测状态能确认和清除、Planning 不获得未来答案、重置复现，以及碰撞和位移记录。实际结果随交付证据记录。


## 本轮验收结果

| 配置（各运行 600 秒） | 过街次数 | 失能恢复 | 新增后续施工 | 路口通行 | 正常交通碰撞 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 8 车，种子 0 | 53 | 10 | 12 | 69 | 0 |
| 12 车，种子 7 | 60 | 11 | 13 | 88 | 0 |

每辆车都完成了路线目标；最后 180 秒内，8 车配置每车至少前进 264 米，12 车配置每车至少前进 265 米。路口等待与事件停驶没有形成永久死锁。真实碰撞专项独立施加测试动作产生 1 次接触，验证停驶、恢复及未穿过固定路障，不混入正常交通的零碰撞结果。

655 项回归测试中 654 通过、1 项因既有原始 fixture 缺失跳过；最终仿真专项 343 项、网页 15 项及隐藏参数检查通过。最终紧凑路线传输/投影缓存版本另跑 180 秒，其采样诊断与长时版本前 180 秒一致。验证支持所列地图、配置和低速范围，不代表任意城市或任意外部动作下的安全保证。
