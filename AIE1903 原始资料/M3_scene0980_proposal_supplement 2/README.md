## 真实场景

原地图文件为 `singapore-onenorth.json`，文件版本 1.3。导出的 8 段地图线、29 个顶点与该文件逐点一致。输出保存地图版本、SHA-256、帧号、观测时间和已匹配的地图要素 ID。地图版本用于追溯数据文件，真实道路变化的时间顺序仍未知。

在 T004 的 15 帧局部匹配中，0 帧超过由同场景 T001 得到的参考阈值。最终判定覆盖率为 0/7，因为 1 个局部匹配窗口和 6 个未匹配候选都缺少可确认的有效覆盖率。LD003 和 LD004 保留优先复核标记。占道候选单独进入通行复核。真实场景的准确率指标留空，独立真值标签尚未提供。

### 上游补齐覆盖证据后

在 `results/coverage_input_template.csv` 填写同一目标段的总长度、视野内长度、视野内遮挡长度、有效观测长度和证据来源。长度应来自可复核的投影或标注。有效长度必须同时满足视野、遮挡、画质和对齐要求。未知值留空，确认为零才填 0。

```bash
python coverage_from_lengths.py filled_coverage.csv coverage_results.csv
```

脚本分别计算视野内长度 / 目标总长度、遮挡长度 / 视野内长度、有效长度 / 目标总长度。视野内长度为零时，遮挡率留空。可将新覆盖结果与区域复核报告按记录 ID、帧号和地图版本连接，再重审现有判定。脚本单独输出覆盖结果，交接文件仍记录本次真实场景的现有证据。

## Proposal 备选实验

从 T004 的 15 帧取 3 个不重叠的 5 帧窗口。对同一个直线地图要素沿统一的车道法向模拟七种偏移（0、±0.08、±0.16、±0.30 m）。固定对应关系，偏移后的残差等于实际残差减去地图偏移。0 表示未注入地图编辑。另模拟三档观测质量和有无单帧 +0.20 m 观测偏差，形成 126 个有脚本标签的窗口变体。覆盖质量由等长目标分段的脚本掩码提供。偏移实验只评估可信度规则，匹配器和相机投影保持在实验范围之外。

| 方法 | 判定方式 |
| --- | --- |
| 几何阈值 | 任一帧的横向绝对残差超过 T001 的经验 P95。 |
| 标准化检验 | 任一帧的平方标准化残差 T 超过 T001 的经验 P95。 |
| 质量门控加多帧证据 | 有效覆盖率至少 70% 的帧计入有效帧。至少 3 帧有效、至少 3 帧连续超阈值且有效帧的支持比例至少 70%，才输出疑似变化。 |

精确率、已判定召回率、F1 和误报率在给出明确判定的样本上计算。证据不足和待复核均算弃判。全体正例召回率把弃判的正例留在分母。分母为零的指标留空。

| 方法 | 明确判定 / 全部 | F1（已判定） | 误报率（已判定负例） | 全体正例召回率 |
| --- | ---: | ---: | ---: | ---: |
| 几何阈值 | 126/126 | 73.3% | 33.3%（6/18） | 61.1% |
| 标准化检验 | 126/126 | 94.6% | 50.0%（9/18） | 97.2% |
| 质量门控加多帧证据 | 36/126 | 94.1% | 0.0%（0/9） | 22.2% |

在这组设定下，质量门控减少了误报，同时放弃了许多有脚本变化的窗口。尤其是间歇可见组，中间一帧失效会打断连续支持，42 个窗口里有 34 个需要进一步复核。所有变体共享同一场景的少量观测，只用于说明规则的取舍。真实场景泛化与独立标定仍待验证。

## 复现

把此前的 `scene0980_step1_delivery_v1.zip`、`singapore-onenorth.json` 和 `scored_candidates.csv` 放进解压目录。在已经配置 NumPy 和 Matplotlib 的项目环境里运行：

```bash
python run_supplement.py scene0980_step1_delivery_v1.zip singapore-onenorth.json scored_candidates.csv
```

其余四个 Python 文件是前面四步的原有分析程序，入口脚本直接复用它们。需要新环境时，先运行 `python -m pip install -r requirements.txt`。
