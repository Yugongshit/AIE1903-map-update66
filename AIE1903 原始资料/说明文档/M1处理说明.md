## 全量实际投影

新增m1_project_all.py，对frames.jsonl内每个LiDAR时刻的七路同步相机执行City地图与City点云到图像的转换，不读取变化标签。每帧重新读取原始点云，检查已保存City坐标与位姿变换的结果，落盘float32误差要求小于1mm；此阈值为计算检查，不代表物理定位精度。

projections/相机名/时间戳.npz保存点云原始索引、原图尺度像素坐标、相机深度、地图投影线段、地图对象字典索引、camera_from_city矩阵及实际K。对应JPEG为最大800×600的检查图；使用NPZ坐标做算法输入时无需按JPEG尺寸解释。地图线段每0.5m以内细分，保守省略跨画面边界或近裁剪面的短片段，不代表完整对象可见性或删除证据。

叠加图青点为LiDAR，红线为车道边界，黄线为横道边缘，绿线为可行驶区域边界。未执行遮挡剔除，线条可能穿过车辆，不能据此认定投影错误或道路变化。局部地图使用M1选出的30m邻域对象，其完整几何可能延伸出30m。

完成状态、帧数及视图数以projections/summary.json为准，逐视图索引为projections/index.csv。m1_check_projections.py检查全部像素范围、计数、重投影一致性，并输出validation.json及review_sheet.jpg。

## 使用入口

工作区根目录运行：

```powershell
python Argoverse工作区/m1_prepare.py
python Argoverse工作区/m1_validate.py
python Argoverse工作区/m1_project_all.py
python Argoverse工作区/m1_check_projections.py
```

第一条会重新生成同名派生结果，第二条检查全部输出并生成总览。依赖numpy、scipy、Pillow及安装在Argoverse工作区/.runtime内的pyarrow。

输出位于m1_outputs/场景ID/：frames.jsonl为统一帧索引，points_city为点云，calibration.json为标定，map_source.json为地图来源，summary.json与validation.json为检查结果，qa及qa_contact_sheet.jpg为投影图。记录中的相对路径以Argoverse工作区为基准。
