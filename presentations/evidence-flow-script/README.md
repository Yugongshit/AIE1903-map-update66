# Bilingual speaker script: evidence and planning flow

[Download the updated Chinese/English Word script](111_Evidence_Flow_Bilingual_Script.docx)

An eight-slide, conversational script for Part 2 Module 3 and Part 3. Chinese and English are alternative versions, each planned for about two minutes. A third page provides bilingual preparation notes outside that timing.

The update explains the planned scene recording, the supporting test results and decision logs, and the proposal's planning-before-maintenance sequence. Planning uses the current prior map and available change/reliability evidence. Maintenance then decides what to retain. The full demonstration remains planned; current replay outputs alone do not establish completed planning or map write-back.

Sources: the group proposal, pages 1, 3 and 4; the repository perception pipeline and visualization documentation. The PPT is unchanged.
