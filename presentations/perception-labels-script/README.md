# Bilingual script using the Perception classification interface

[Download the updated Chinese/English speaker script](111_Perception_Labels_Bilingual_Script.docx)

Two pages, covering the eight-slide personal section in about two minutes per language.

This revision follows the clarified team interface: Perception supplies short-term and long-term classifications. Map Maintenance uses those classifications, reliability information and geometry checks to choose temporary event records or base-map updates, with uncertain cases retained for review.

The main spoken demo description shows the inputs, classifications, map outcomes, planning outputs and decision records. Revisits are not a required step in this workflow. The final slide's script distinguishes a predicted long-term label from proof of real-world permanence and retains limits on generalization and road safety.
